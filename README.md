## Pocket Pet for XIAO ESP32-S3

A pocket-pet project based on the Seeed Studio XIAO ESP32-S3 microcontroller.

- XIAO ESP32-S3: https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/
- Display options:
	- OLED SSD1306 I2C 128x64
	- Samsung LCD 84x48: https://cdn.shopify.com/s/files/1/1509/1638/files/LCD_Display_84x48_Pixel_Datenblatt.pdf?6488019443713923040
- Power: battery, depending on the final form factor

Use the Python generator in this repository to rebuild `GeneratedSprites.h` from the PNG sprite assets.
